# PiPER X 实机动力学参数辨识报告

**记录日期：** 2026-10-29

**数据：** 120 秒实机记录，100 Hz；筛选后 11,956 个有效样本

**当前结论：** URDF 派生的最小基动力学拟合已完成；逐连杆真实质量、质心和惯量尚未被这批力矩数据唯一辨识，结果不适合直接用于控制。

## 1. 本次做了什么

本次针对 PiPER X 重新设计并运行了辨识流程。核心修改是先从真机对应的 PiPER X 模型构造动力学回归器，推导最小参数基，再用实机数据拟合。旧流程直接拟合 78 个标准参数并把 QR 解中的零值解释为连杆质量，现已判定无效。

辨识模型写为

\[
\tau=Y(q,\dot q,\ddot q)\theta+\varepsilon,
\]

其中 \(\theta\) 包含 60 个刚体惯性参数，以及每个关节的粘性摩擦、平滑库仑摩擦和偏置，共 78 个标准参数。

### 1.1 从 PiPER X URDF 推导最小参数基

模型运动学和名义惯性取自实验代码快照中的 `piper_x.urdf` 与 `nominal_x.json`，并沿快照 `simulation.py` 的模型构造路径生成动力学模型。使用 URDF 关节范围内的通用关节位置、速度和加速度建立结构回归器 \(Y_g\)。以 CAD 名义质量和惯性给惯性参数定义特征尺度矩阵 \(S\)，对数值回归器做 SVD：

\[
Y_g S=U\Sigma[V_r\;V_0]^T,
\]

保留可观测子空间 \(V_r\)，构造

\[
\theta=S(V_r\beta+V_0\gamma),\qquad
Y_{\min}=YSV_r.
\]

真机力矩预测只依赖最小基参数 \(\beta\)，不依赖零空间坐标 \(\gamma\)。本模型得到刚体惯性秩 **36/60**；加入 18 个摩擦和偏置项后，秩为 **54/78**，标准参数零空间维数为 **24**。因此这 54 个最小基系数是可辨识的动力学组合，不是六个 link 的质量表。

### 1.2 拟合、验证和物理约束恢复

按完整 10 秒周期划分训练和留出数据：训练集 955 点、留出集 957 点。先在 54 维最小基上做最小二乘拟合，并用留出周期验证。另用完整 11,956 点重拟合，作为全量训练内结果。

为了避免再输出零质量或非物理惯量，本次还在最小基框架中联合优化 \(\beta\) 和标准参数零空间坐标 \(\gamma\)，并加入：

- 每个连杆的伪惯量矩阵半正定约束，保证质量与惯性满足刚体物理可行性；
- 连杆质量限制为对应 CAD 名义质量的 0.5–1.5 倍；
- COM 限制在 PiPER X 碰撞网格凸包外扩 10 mm 的范围内；
- 伪惯量二阶矩受相同网格外包盒约束；
- 粘性和光滑库仑摩擦系数非负，常值偏置允许正负；
- 对 CAD 伪惯量使用 log-det 几何先验，正则强度按留出完整周期选择。

这一步允许重新拟合最小基参数，因为无约束最小二乘的 \(\hat\beta\) 单独固定后，无法找到满足伪惯量物理约束的标准参数实现。

## 2. 解决了什么问题

### 2.1 排除了“连杆质量为零”的伪结论

旧流程对秩亏的 78 维标准参数直接求解。QR 求解器在不唯一方向上选择零值，之后再把这个数值代表解换算为 link 质量，便产生了近零质量、COM 不可计算和非物理惯量。这不是机械臂没有质量，而是把不可辨识的解误当成唯一物理参数。

现在已将旧逐连杆表格和旧结果标记为过期；当前逐连杆候选质量均为正，并通过本报告所列的伪惯量与几何检查。但它们仍是先验约束下的一种可行实现，不能称为测得的真机质量。

### 2.2 修正了虚假的 65 阶秩判断

第一版对回归器逐列按 RMS 归一化，把有限差分在结构零列留下的舍入噪声放大，误报为 65 阶。当前从名义 CAD 质量、长度和惯性构造尺度 \(S\)，不再放大微小列噪声，得到 54/78。独立随机状态回归器重构相对误差为 \(4.15\times10^{-14}\)，保留/丢弃奇异值间隔约 \(2.30\times10^9\)。

### 2.3 确认了模型对应关系

当前模型使用实验快照中的 PiPER X URDF、名义惯性和动力学代码，没有混入仿真工程里另一型号机械臂的参数。逐关节 URDF 变换、关节轴向和名义惯性均通过模型对齐审计。另用 40 组独立通用状态核对回归器力矩与同一模型的 `mj_inverse`，最大力矩差为 \(7.86\times10^{-10}\) N·m。

## 3. 辨识结果

以下相对误差均为残差范数除以目标力矩范数。目标力矩通过 PiPER X SDK 型号参考系数由电流换算；这些系数尚未在本机做台架标定。

|---|---:|---:|---:|
| 54 维最小基 OLS | 7.06% | 7.08% | 7.33%（训练内） |
| 物理约束候选 | 7.47% | 7.45% | 7.66%（训练内） |

## 4. 对“质量是不是辨识出来了”的回答

**没有唯一辨识出六个 link 的真实质量。** 结构零空间有 24 维，质量方向本身也几乎完全落在不可观测子空间：在 CAD 尺度下，link1–6 的质量坐标可观测投影约为 `1.7e-14, 7.8e-15, 0.0052, 0.0072, 0.0073, 0.0074`。这意味着质量、质心一次矩和惯量在当前运动与力矩模型中可以相互补偿。

可以确认的是：最小基力矩预测拟合成功，且能在同一记录的留出周期上维持约 7.08% 的残差范数比。不能确认的是每个连杆分别有多少质量、COM 和惯量。留出周期来自同一条 120 秒记录，并非独立采集；因此验证范围也限于这条轨迹。

本机电流到输出力矩比例、关节绝对零位和方向尚未独立标定；采集时底座/桌面运动也没有测量。上述误差会进入参数拟合。当前结果不适合直接用于控制或作为改 CAD 的真值。

## 5. 算法对照和公开方法

同一 54 维基和留出数据上比较了普通 OLS、按关节目标 RMS 加权的 WLS，以及 Huber IRLS。整体残差范数比依次为 7.076%、7.345%、7.370%；Huber 迭代 34 次收敛，但没有优于 WLS 或 OLS 的整体验证结果，因此没有替换主拟合方法。WLS/Huber 的宏平均逐关节相对误差较低，说明它们改变了轴间权重取舍，不代表动力学参数更真实。

公开项目调研显示，PiPER 专用开源项目可参考真机采集和傅里叶激励设计，但其直接全参数回归不消除结构不可辨识性；FloBaRoID 提供了物理一致性 SDP、CAD 先验和基参数恢复的参考，BIRDy 提供多估计器比较；PiPER-L 的 MuJoCo SysID 使用伪惯量参数化和轨迹级位置/速度残差，但机型和控制输入假设与本次 PiPER X 不同。本次实现结合了最小基、物理伪惯量、CAD/网格边界和完整周期验证，而不是直接照搬其他机型的数值参数。

## 7. 后续要获得可信逐连杆质量

建议先固定并测量基座，校准本机电流到输出力矩比例与关节零位，再补充独立激励轨迹和独立会话验证。若必须获得每个 link 的质量和 COM，应加入连杆/夹爪称重或独立质量分布测量；只增加最小二乘迭代次数不能补回数据中不可观测的参数方向。
