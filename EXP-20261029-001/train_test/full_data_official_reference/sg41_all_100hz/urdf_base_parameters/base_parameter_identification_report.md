# PiPER X URDF 结构最小参数集辨识

> 本报告先从快照 URDF 派生动力学回归器并用通用状态确定最小独立基，再用真机训练周期估计基参数，最后用留出的完整周期验证。全量重拟合结果另列为训练内结果。

## 1. 为什么先做最小参数集

标准形式 `tau = Y theta` 有 60 个刚体惯性分量；加 18 个摩擦/偏置分量后共 78 个系数。由于回归矩阵秩亏，78 个标准参数不能全部独立辨识，因此要先从 URDF 派生的回归矩阵构造最小坐标，再用真机数据估计这些可辨识组合。

具体地，用名义 URDF/CAD 惯性定义参数特征尺度 `S=diag(m0, m0*ell, m0*ell, m0*ell, m0*ell², ... )`，摩擦项使用 `[1, 0.5, 1]` 的逐关节尺度。对 `Y_g S=U Σ Vᵀ` 做 SVD，取秩 `r=54` 对应的右奇异向量 `V_r`，最小回归器为 `Y_min=Y S V_r`，然后用真机训练数据拟合 `τ≈Y_min β`。标准参数与基参数关系为 `β=V_rᵀ S⁻¹ θ`。
剩下的 24 维零空间记为 `V_0`，所以 `θ=S(V_r β+V_0 γ)` 中不同的 `γ` 给出相同的最小基预测。这说明单靠关节力矩数据不能唯一恢复逐连杆质量、COM 与惯量。

## 2. URDF 派生的结构秩与基参数

三个独立通用状态批次得到刚体惯性结构秩 **36/60**；添加 18 个逐关节摩擦/偏置列后的结构秩为 **54/78**。独立验证批次上所选基的秩是 54/54，全部 78 列由该基重构的相对误差为 4.151e-14。

另用 40 个独立通用状态直接核对 `Y theta_CAD` 与同一 PiPER X MuJoCo 模型的 `mj_inverse`，最大绝对力矩误差为 7.863e-10 N·m，相对最大参考力矩为 1.938e-13。这验证了回归器参数顺序、link6 合并惯性和逆动力学实现相互一致。

按 CAD 特征尺度检出的近零回归列为：link1.m, link1.hx, link1.hy, link1.hz, link1.Ixx, link1.Iyy, link1.Ixy, link1.Ixz, link1.Iyz, link2.m, link2.hz。旧的逐列 RMS 归一化会把有限差分的舍入噪声放大，错误得到 65 维秩；本版改用物理特征尺度，且奇异值在保留的 54 维和其余 24 维之间有明显间隔。
单独质量坐标在可观测子空间中的投影范数依 link1–6 为 1.681e-14, 7.779e-15, 0.005204, 0.007213, 0.007341, 0.007355；这不是置信区间，而是结构可辨识性审计。link1/2 质量列为结构零列，其他质量坐标也几乎完全落在可与一阶矩/惯量互相补偿的零空间中，因此数据本身不能独立给出六个 link 的质量。

NPZ 保存 `V_r`、`V_0` 和 CAD 特征尺度；方向 CSV 保存可检查的基方向。54 个系数只描述模型力矩映射，不能直接解释成某个 link 的质量、质心或惯量。

真机训练周期上的基矩阵秩为 54/54；留出周期为 54/54；全量数据为 54/54。

## 3. 拟合与留出周期验证

训练/留出按完整 10 秒周期划分，训练周期为 2、4、6、8、10，留出周期为 1、3、5、7、9。目标力矩按 PiPER X SDK 型号参考 KBC 系数将实测电流换算，尚未针对本机单独标定。

| 数据段/用途 | 相对误差（残差范数/目标范数） | 样本数 |
|---|---:|---:|
| 训练周期拟合 | 7.06% | 955 |
| 留出完整周期验证 | 7.08% | 957 |
| 全量 120 秒重新拟合（训练内） | 7.33% | 11956 |

逐关节 RMSE、目标 RMS、归一化误差和 R² 在 `base_parameter_validation_metrics.csv`。最终全量基参数在 `urdf_structural_base_parameters.csv`；训练/验证预测在 `base_parameter_fit.npz`。

## 4. 这一步能说明什么

- 训练集上的 54 维最小基拟合在留出周期上得到 7.08% 力矩残差范数比；这表示同一条记录内的周期外推表现，不等于实物惯性参数已辨识成功。
- 本报告不从 54 维最小基向量反造逐连杆参数；从 β 恢复标准惯性参数存在 24 维零空间。需要额外约束、几何先验或称重/质心测量才能选取一组逐连杆实现。
- 留出整周期误差是同一真机 session 中的验证，不是另一条独立轨迹。全量拟合误差只能看作训练内拟合。

## 5. 结果文件

- `base_parameter_identification_report.json`：结构秩、URDF/数据来源、算法设置与所有指标。
- `urdf_structural_base_parameters.csv`：54 个最小基系数、训练集估计和全量重拟合估计。
- `urdf_structural_base_directions.csv`：每个最小基坐标在 78 个标准回归参数上的方向系数。
- `base_parameter_validation_metrics.csv`：训练、留出和全量逐关节误差。
- `base_parameter_fit.npz`：最小基矩阵 V、未观测零空间 V0、CAD 特征尺度 S、系数向量和对应预测。

## 6. 适用边界

- 结构秩是对指定 URDF、回归器和通用状态范围进行的数值 SVD 判断，不是符号代数证明。
- SDK 电流到力矩系数尚未对这台机械臂单独标定，所有力矩误差仍依赖该型号参考系数。
- 基座/桌面运动没有测量，当前模型假定基座固定；关节方向和绝对零位也没有独立校准。
- 留出周期来自同一段 120 秒记录，不是独立采集的轨迹。
