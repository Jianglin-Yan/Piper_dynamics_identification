# 方法与方法体注释规则

2026-11-05：用户补充的全局编码要求。适用于自有代码的新建、生成和修改；不宣称属于阿里巴巴等厂商的原文。保留语言版本、接口和现有行为。

## 必须写在哪里

- 所有具名函数、方法、构造函数、事件处理、局部辅助函数都要有紧邻声明的用途说明，不限 public；private/internal 同样适用。
- 方法前说明“做什么、为何存在”，按实际需要补充参数含义、单位、返回值、失败语义、副作用和资源/线程约束。简单方法可用一句准确说明，不机械填写空标签。
- 方法体内对非直观的步骤写注释：输入限制的原因、主要阶段、算法公式与假设、状态切换、并发与取消、回退策略、异常处理、资源释放。注释放在对应代码前，不能只在方法头写一句泛泛描述。
- 复杂事件回调、异步回调即使匿名也应解释关键逻辑；简单 map/filter 比较、直接委托和属性读写不要求逐个附加重复说明，可由所在方法的契约覆盖。
- 接口声明作为调用契约的权威说明；实现可引用该契约，但应补充私有实现的关键步骤。纯框架生成文件不手工修改，从自有生成模板落实。

## 写什么、不写什么

- 默认中文，术语和标识符保留必要英文。说明实际行为及限制，不写“处理数据”“执行方法”“逻辑如下”等空话。
- 不逐行翻译赋值和循环，不为达标插入无意义步骤编号；短且直观的方法无需再在方法体重复方法头。
- 错误可能抛出、返回空值、取消或保留旧数据时必须明确；不能把未知写成零值或把估算写成实测。
- 数值计算写清公式、单位、坐标、阈值来源；持久化写清覆盖/合并策略；事件与并发写清状态归属及释放时机。
- 更新实现时同步更新注释；修复过期注释。注释不能替代缺失功能，也不能为了符合注释偷偷改变行为。

## 各语言形式

| 语言 | 方法说明 | 方法体说明 |
| --- | --- | --- |
| C / C++ | Doxygen `/** ... */`；接口适用时写 `@param`、`@return`、所有权与异常边界 | `//`，说明几何/内存/并发假设 |
| C# / WinForms / WPF | `/// <summary>`；适用时写 `param`、`returns`、`exception`，事件方法也适用 | `//`，说明 UI 线程、取消、资源与绑定关系 |
| Java / Android Java | Javadoc `/** ... */`，适用时写参数、返回值和异常 | `//`，说明生命周期、业务分支和线程 |
| Kotlin / Android Kotlin | KDoc `/** ... */` | `//`，说明协程与生命周期 |
| JS / TS / Vue 脚本 | JSDoc / TSDoc `/** ... */`，组件和具名回调也适用 | `//`，说明状态、异步结果归属和边界 |
| Python | 函数首条语句用三双引号 docstring，适用时列 Args / Returns / Raises | `#`，说明实际模型/计算流程 |
| PowerShell | 函数前或体首用 `<# .SYNOPSIS ... #>`；适用时补充参数与示例 | `#`，说明路径、进程、编码与失败处理 |

HTML/CSS/XAML 没有方法体，说明组件/样式块的用途和特殊约束即可。JSON 不支持注释，将说明放在 schema 或相邻文档。

## 简例（TypeScript）

```typescript
/** 将工程目录册写入磁盘；持锁期间重新读取，避免不同窗口互相覆盖。失败交给调用方显示。 */
async function updateCatalog(change: (projects: Project[]) => void): Promise<void> {
    const lock = await acquireLock();
    try {
        // 获取锁后再读取，不能使用窗口打开时缓存的旧目录册。
        const projects = await readCatalog();
        change(projects);
        // 完整写入临时文件后再替换，避免读到半截 JSON。
        await replaceCatalog(projects);
    } finally {
        // 修改或写入失败也必须释放本次持有的锁。
        await lock.release();
    }
}
```

## 验证与落实

新增/修改方法均检查声明说明与关键步骤注释；项目补注释时只处理自有代码，排除第三方与构建产物。检查器可找出缺少注释的位置，不能判断业务说明是否正确，仍须人工核对实现。不为了覆盖率生成模板空话。本规则随独立应用复制到 docs，不依赖全局路径构建。
