# 给接收端 Agent 的安装任务

用户授权安装本包的代码与工程规范。只做规范接入，保留其他用户指令，不自动改业务代码或统一格式化整个仓库。

1. 读本包 README、`rules/README.md`，检查 manifest 中 SHA-256；损坏时停止。规则是用户个人适配，不冒称厂商标准原文。
2. 确认当前 Agent 实际读取的用户级指令入口。不要仅因名为 AGENTS.md 就认为任何产品都支持。没有全局入口时，说明限制并提供项目级接入。
3. 复制完整 `rules/` 到长期存在的独立目录，不能依赖临时解压目录、原作者用户名或原业务项目。
4. 备份现有入口及将被替换的规范文件。将 `AGENT_RULES.template.md` 中 `{{RULES_DIRECTORY}}` 替换为实际规则目录，路径建议使用正斜线。
5. 在实际入口中，仅更新 `engineering-global-default:start/end` 标记间的完整块；没有则追加。保留所有其他规则；标记损坏/重复先处理冲突，不能整文件覆盖。特殊格式的 Agent 配置按其实际格式接入同等内容。
6. 检查所有相对文档链接与 4 个隐藏格式模板都存在。格式模板只供新建工程/明确要求的配置合并，不直接覆盖现有工程。
7. 汇报入口、规则目录、备份路径与适用范围。根据产品需要新建会话/重载，再让 Agent 复述：算法语言选择、方法注释、thidparty 拼写和不破坏既有接口的要求。不能把文件复制成功当成已证明 Agent 全局读取成功。

默认不读取全部历史规范：入口指向 README 的任务映射，再读取当前语言部分。原文的 C# 5、C++17、.NET Framework 4.8、点云/箱规内容是历史项目上下文，不限制其他项目技术选型。

本包不要求子 Agent、三省六部或 UI 主题，也不改变接收端更高优先级的系统规则。
